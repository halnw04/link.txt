# Game Launcher

ตัวเปิดเกมบนเว็บที่เล่นได้หลายบัญชีในหน้าต่างเดียว (Electron)

## ฟีเจอร์
- **จำรหัสแยกบัญชี**: แต่ละบัญชีมีคุกกี้และล็อกอินของตัวเอง รหัสผ่านเก็บแบบเข้ารหัสด้วย DPAPI ของ Windows
- **กรอกให้อัตโนมัติ**: พอหน้าเกมขึ้นช่องรหัสผ่าน โปรแกรมกรอกชื่อและรหัสให้ ผู้เล่นกดเข้าเกมเอง
  รหัสจะส่งให้เฉพาะหน้าที่อยู่โดเมนเดียวกับลิงก์เกมที่ตั้งไว้เท่านั้น
- **เปอร์เซ็นต์ตอนโหลด**: ประมาณจากจำนวนไฟล์ที่โหลดเสร็จ ถ้าไม่ขยับเกิน 20 วินาทีจะขึ้น "โหลดค้าง" พร้อมปุ่ม **ลองอีกครั้ง** / **รีเฟรชเกม**
- **พักภาพหลายบัญชีในคลิกเดียว**: ติ๊กเลือกบัญชีได้ ถ้าไม่ติ๊กเลย จะทำกับทุกบัญชียกเว้นตัวที่เปิดดูอยู่
  - *พักภาพ*: ปิดหน้าเกมทิ้งเพื่อคืน RAM (ตัวละครจะออกจากเกม) ตอนคืนภาพจะโหลดใหม่และกรอกรหัสให้
  - *พักเบา*: ซ่อนไว้ ยังออนไลน์อยู่ ปิดเสียง และลดการใช้ CPU
- **จับภาพค้าง**: ถ้าภาพในจอที่ดูอยู่ไม่ขยับเลย 15 วินาที (เช่น ตายแล้วกลับเมืองแล้วจอค้าง) หรือหน้าเว็บไม่ตอบสนอง จะขึ้นปุ่มรีเฟรช

## รัน / build
```bash
npm install
npm start          # รันแบบ dev
npm run dist       # สร้าง .exe แบบ portable (ต้องรันบน Windows)
```

## ยังไม่มี
- หน้ารวม HP/SP/EXP: ต้องรู้ก่อนว่าเกมเก็บค่าพวกนี้ไว้ตรงไหน
